# Sales Performance Analysis

## Project Overview
This project analyzes retail sales data using Microsoft Excel to uncover sales trends, customer demographics, product category performance, and key business insights through Pivot Tables, KPI calculations, and dashboard visualization.

## Tools Used
 Microsoft Excel
 Pivot Tables
 Pivot Charts
 Dashboard Design
 Data Analysis

## Key Findings
 Total Sales Revenue: ₦456,000
 Total Quantity Sold: 2,514
 Average Order Value (AOV): ₦456
 Top Product Category: Electronics (₦156,905)
 Female Customers: 510
 Male Customers: 490


## Analysis Components
 Raw Sales Dataset

 Sales Revenue Analysis
